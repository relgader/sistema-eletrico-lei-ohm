# ⚡ Simulador Elétrico

Simulador interativo de circuitos elétricos desenvolvido para demonstrar a **Lei de Ohm** e conceitos básicos de eletricidade de forma visual e dinâmica.

## 🚀 Funcionalidades

- Ajuste de tensão (0 a 24 V) e resistência (1 a 100 Ω).
- Cálculo automático da corrente elétrica e potência.
- Lâmpada com brilho dinâmico conforme a potência.
- Inversão da polaridade da bateria.
- Indicação do sentido da corrente elétrica.
- Animação de partículas representando a corrente no circuito.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- SVG
- Git e GitHub

## 📐 Fórmulas utilizadas

**Lei de Ohm:**

\[
I = \frac{V}{R}
\]

**Potência elétrica:**

\[
P = V \times I
\]

## 💻 Como executar

1. Clone o repositório:
   ```bash
   git clone URL_DO_REPOSITORIO
   ```
2. Abra a pasta no VS Code.
3. Execute o index.html no navegador ou utilize a extensão Live Server.
